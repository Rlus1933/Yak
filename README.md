# 약 챙김이

어르신이 약 먹는 시간을 놓치지 않도록 도와주는 복약 알림 웹앱입니다.
실용적인 기능에 웃음 요소를 섞어 발표 시연용으로 만들었습니다.

## 실행 방법

`index.html`을 내려받아 크롬 같은 브라우저로 열면 바로 실행됩니다.
설치할 것은 없습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 바로 실행되는 완성본 (고양이 사진 2장이 코드 안에 들어 있음) |
| `src.html` | 읽기용 원본 코드 (사진 자리에 `__CAT__`, `__SLAP__` 표시만 있음) |
| `cat.jpg`, `slap.jpg` | 앱에 쓰인 고양이 사진 |

## 주요 기능

### 잔소리 단계 상승
약 시간이 지나도 먹지 않으면 알림이 점점 세집니다.

| 지난 시간 | 단계 | 알림 |
|---|---|---|
| 0~9분 | 1단계 | "약 드실 시간이에요 😊" |
| 10~19분 | 2단계 | "혹시... 잊으신 건 아니죠?" (문구가 흔들림) |
| 20~29분 | 3단계 | "손주가 걱정하고 있습니다 😢" + 우는 손주 그림 |
| 30분~ | 4단계 | 화면 전체 빨간색 + 사이렌 + "약! 약! 약!" |

### 사투리 모드
표준어, 경상도, 전라도, 충청도 말투 중에서 고를 수 있습니다.
사투리 문구는 일반적으로 알려진 표현을 바탕으로 쓴 것이라 실제 말투와 다를 수 있습니다.

### 의심하는 고양이 인증
"먹었어요"를 누르면 50% 확률로 고양이가 의심하며 인증을 요구합니다.
- 문구 그대로 따라 쓰기 / 약 이름 맞히기 / "꿀꺽" 버튼 3번 누르기 중 하나가 무작위로 나옵니다.
- 3번 틀리면 "꾸짖을 갈!!!" 화면과 효과음이 나오고, 약은 먹지 않은 것으로 남습니다.

### 포인트와 상점
- 약을 먹으면 10포인트, 하루치를 다 먹으면 30포인트를 더 받습니다.
- 포인트로 칭호, 화면 테마, 기프티콘을 살 수 있습니다.
- **기프티콘은 발표용 가짜이며 실제로 사용할 수 없습니다.**

### 약 직접 추가
시간과 약 이름을 입력해 약을 추가하고 삭제할 수 있습니다.

### 알 이스터에그
왼쪽 아래 알을 10번 누르면 깨지면서 비밀 버튼이 나옵니다.

| 버전 | 특징 | 포인트 이름 |
|---|---|---|
| 아기용 | 분홍 테마, 아기에게 말하듯 다정한 말투 | 칭찬 스티커 |
| 청년용 | 보통 크기 글자와 버튼, 짧은 말투 | 건강 포인트 |
| 어르신용 (기본) | 큰 글자와 버튼, 사투리 모드 사용 가능 | 건강 포인트 |
| 조상님용 | 흑백 화면, 떠다니는 유령, 아주 큰 버튼 | 환생 포인트 |

### 시연 모드
오른쪽 아래 버튼으로 켜고 끕니다.
켜면 시간 건너뛰기(+5분, +10분, +1시간 등) 도구가 보이고,
경보 화면과 인증 창을 건너뛸 수 있습니다.

## 저장 방식

포인트, 칭호, 테마, 추가한 약은 브라우저의 `localStorage`에 저장됩니다.
그래서 사용하는 브라우저마다 따로 저장되며, 서버로 전송되지 않습니다.

## 사용 기술

HTML, CSS, JavaScript (외부 라이브러리 없음)
- 글꼴: Google Fonts (Jua, Noto Sans KR, Song Myung)
- 소리: Web Audio API로 사이렌과 효과음을 직접 만들어 재생
